# Email inbox template

This repository is a visual starter, not a connected mailbox. Preserve the clear Gmail-inspired folder and conversation layout and the original Nexa identity.

- Start with README.md. Customize index.html, styles.css, and app.js; there are no dependencies or backend yet.
- Keep sample data identified as sample until real mailbox data is connected. Do not present local demo actions as successful sending or synchronization.
- Ask for missing business requirements when implementing email providers, sending, retention, and team permissions. Never commit tokens, private messages, or customer information to this public upstream.
- Imported projects should use their own Cloudflare account, Worker name, resources, and secrets. Keep upstream history for future merges.
- Run npm run build, check JavaScript syntax, and inspect desktop/mobile browser layouts and the search/filter controls after changes. Add meaningful backend tests as real functionality is implemented.
